# PAX Köksplanerare — APK Demo

Müşteri odaklı PAX mutfak planlayıcı prototipi.

## Demo özellikleri
- Mutfak genişlik ve derinlik ölçüsü
- Ürün kategorileri
- Ürün ekleme
- Gerçek ölçü oranına göre ürün boyutu
- Parmakla ürün sürükleme
- Oda sınırları içinde tutma
- Seçilen ürün sayısı

Android package: `se.paxkok.koksplanerare`

GitHub Actions build'i tamamlandığında `PAX-Koksplanerare-APK` artifact'ı oluşur.
